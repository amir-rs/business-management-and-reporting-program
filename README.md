# سیستم مدیریت کافه (Cafe Management System)

یک سیستم کامل مدیریت کافه با قابلیت‌های پیشرفته برای مدیریت فروش، موجودی، هزینه‌ها و گزارش‌گیری مالی.

## ویژگی‌های اصلی

### 🛍️ مدیریت فروش و موجودی
- ثبت فروش محصولات با محاسبه خودکار موجودی
- پیگیری مصرف مواد اولیه بر اساس دستور تهیه
- مدیریت موجودی مواد اولیه با هشدار کمبود

### 💰 قیمت‌گذاری دقیق
- محاسبه خودکار هزینه مواد اولیه هر محصول
- تعیین قیمت فروش بر اساس هزینه‌ها و حاشیه سود
- تحلیل سودآوری محصولات

### 📊 گزارش‌گیری مالی
- گزارش‌های روزانه و ماهانه فروش
- تحلیل نقطه سر به سر (Break-even Analysis)
- محاسبه سود و زیان با جزئیات کامل

### 📈 مدیریت هزینه‌ها
- ثبت هزینه‌های عملیاتی (اجاره، حقوق، قبوض و...)
- تأثیر هزینه‌ها بر نقطه سر به سر
- تحلیل توزیع هزینه‌ها

## نصب و راه‌اندازی

### پیش‌نیازها
- Python 3.8 یا بالاتر
- pip (مدیر بسته‌های Python)

### مراحل نصب

1. **کلون کردن پروژه:**
```bash
git clone <repository-url>
cd cafe-management-system
```

2. **ایجاد محیط مجازی:**
```bash
python -m venv venv
```

3. **فعال‌سازی محیط مجازی:**
```bash
# Windows
venv\Scripts\activate

# macOS/Linux
source venv/bin/activate
```

4. **نصب وابستگی‌ها:**
```bash
pip install -r requirements.txt
```

5. **اجرای برنامه:**
```bash
python app.py
```

6. **دسترسی به برنامه:**
مرورگر خود را باز کرده و به آدرس `http://localhost:5000` بروید.

## راهنمای استفاده

### 1. شروع کار
- ابتدا مواد اولیه را اضافه کنید (قهوه، شیر، شکر و...)
- محصولات را با دستور تهیه تعریف کنید
- هزینه‌های عملیاتی را ثبت کنید

### 2. مدیریت مواد اولیه
- **افزودن ماده:** نام، موجودی فعلی، قیمت واحد
- **ویرایش:** بروزرسانی موجودی و قیمت‌ها
- **هشدار:** اعلان کمبود موجودی

### 3. تعریف محصولات
- **دستور تهیه:** تعیین مقدار هر ماده اولیه
- **قیمت‌گذاری:** محاسبه خودکار هزینه و سود
- **تحلیل:** بررسی سودآوری محصولات

### 4. ثبت فروش
- انتخاب محصول و تعداد
- محاسبه خودکار قیمت کل
- بروزرسانی موجودی مواد

### 5. گزارش‌گیری
- **روزانه:** فروش، مصرف مواد، سود روزانه
- **ماهانه:** تحلیل مالی کامل، سود و زیان
- **نقطه سر به سر:** محاسبه حداقل فروش برای سودآوری

## ساختار پایگاه داده

### جداول اصلی:
- **RawMaterial:** مواد اولیه (نام، موجودی، قیمت واحد)
- **Product:** محصولات (نام، قیمت، دستور تهیه)
- **Sale:** فروش‌ها (محصول، تعداد، تاریخ)
- **OverheadCost:** هزینه‌های عملیاتی
- **StockMovement:** حرکات موجودی

## API Endpoints

### محاسبات:
- `GET /api/calculate_cost/<product_id>`: محاسبه هزینه محصول
- `GET /api/break_even_analysis`: تحلیل نقطه سر به سر

### گزارش‌ها:
- `GET /reports/daily?date=YYYY-MM-DD`: گزارش روزانه
- `GET /reports/monthly?month=YYYY-MM`: گزارش ماهانه

## نمونه استفاده

### مثال: تعریف محصول کاپوچینو
1. مواد اولیه:
   - قهوه: 18 گرم (1500 تومان/گرم)
   - شیر: 120 میلی‌لیتر (200 تومان/میلی‌لیتر)

2. محاسبه هزینه:
   - قهوه: 18 × 1500 = 27,000 تومان
   - شیر: 120 × 200 = 24,000 تومان
   - کل هزینه: 51,000 تومان

3. قیمت فروش: 85,000 تومان
4. سود: 34,000 تومان (40% حاشیه سود)
